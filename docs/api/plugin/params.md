# Parameters and Forms

Declare what an algorithm can be told as a list of `Param` (no Qt), and let `ParamsForm` build the controls: basic and advanced sections, help, units, dependencies, remembered values and per-user defaults. Used by CytoMetrics' segmenters and assays and by the Gel & Blot stages.
